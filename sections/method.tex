\section{Proposed LLMBO-MO}
\label{sec:method}

Section~\ref{sec:model_section} provides a simulator that maps each charging
protocol $\theta$ to the three objectives $t_c$, $T_p$, and $Q_s$ while checking
the operating constraints. Because every new protocol requires an
 electrochemical--thermal--aging simulation, only a limited number of
candidate protocols can be evaluated in practice. The key issue is therefore
not to increase the number of evaluations, but to allocate the available
simulation budget to informative regions of the decision space.

Bayesian optimization is well suited to this setting because it uses evaluated
samples to construct a surrogate model and sequentially selects promising new
protocols. Its early search, however, is sensitive to the initial design when
only a few simulator observations are available. LLMBO-MO addresses this
weakness by combining a decomposition-based multiobjective Bayesian
optimization backbone with two LLM-assisted search mechanisms: an
LLM-informed initial design and a weight-conditioned regional guidance
mechanism. The LLM only suggests where the numerical optimizer should search;
all objective values, feasibility decisions, surrogate updates, and Pareto
relations are determined from simulator-evaluated data.

\subsection{Overall Framework}
\label{sec:framework}

The framework of LLMBO-MO is illustrated in Fig.~\ref{fig:framework}. Before
sequential Bayesian optimization starts, the LLM generates a pool of candidate
MCC protocols from the battery description, decision-variable bounds, and
qualitative charging knowledge. After protocol-level screening and diversity
selection, a subset of these candidates is combined with randomly generated
valid protocols and evaluated by the battery simulator to form the initial
dataset $D$.

At iteration $t$, a trade-off weight $\mathbf w^{(t)}$ is selected to define the
current multiobjective preference. The three objectives are then scalarized,
and a Gaussian process (GP) is fitted to the resulting scalar observations.
Expected improvement (EI) is used to select the next protocol for simulation.
During the early iterations, the LLM may additionally suggest a promising
region conditioned on $\mathbf w^{(t)}$ and the current optimization state.
Points sampled from this region are used only as additional starting points for
numerical EI maximization. The original acquisition search and the full
decision space are retained. The selected protocol is finally evaluated by the
battery simulator, after which $D$ and the feasible Pareto archive $P$ are
updated. This process continues until the simulation budget is exhausted.

\subsection{Decomposition-Based Multiobjective Bayesian Optimization}
\label{sec:parego_backbone}

The numerical backbone follows a decomposition-based multiobjective Bayesian
optimization strategy~\cite{ref4,refEIMO}. A set of nonnegative weight vectors
$W$ is generated in advance to cover different trade-off directions. At
iteration $t$, one weight vector
$\mathbf w^{(t)}=[w_1^{(t)},w_2^{(t)},w_3^{(t)}]$ is selected from $W$, with
$\sum_{i=1}^{3} w_i^{(t)}=1$. By changing $\mathbf w^{(t)}$ across iterations,
the optimizer sequentially explores different parts of the Pareto front.

Because the three objectives have different numerical scales, the charging-time
and degradation objectives are logarithmically transformed before
scalarization,
\begin{equation}
 y_1(\theta)=\log_{10}\!\frac{t_c(\theta)}{t_{\mathrm{ref}}},\qquad y_2(\theta)=T_p(\theta),\qquad y_3(\theta)=\log_{10}\!\frac{Q_s(\theta)}{Q_{\mathrm{ref}}}.
\label{eq:objective_transform}
\end{equation}
where $t_{\mathrm{ref}}$ and $Q_{\mathrm{ref}}$ are fixed positive reference
values. A small positive floor is applied before the logarithm for numerical
stability. For each objective, the scale $s_{i,t}$ is initially set to a fixed
global range and is replaced by the observed range once the latter exceeds a
prescribed fraction $\rho_R$ of the global range. This prevents the narrow
objective range observed in the first few iterations from dominating the
scalarization.

The scaled objective is defined as
\begin{equation}
 \bar f_{i,t}(\theta)=\frac{|y_i(\theta)-z_{i,t}^{*}|}{s_{i,t}},\qquad i=1,2,3,
\label{eq:objective_scaling}
\end{equation}
where $z_{i,t}^{*}$ is the best observed value of the $i$th transformed
objective. The current multiobjective problem is then converted into a scalar
subproblem using the augmented Tchebycheff function,
\begin{equation}
 g_t(\theta)=\max_{i=1,2,3}\{w_i^{(t)}\bar f_{i,t}(\theta)\}+\rho\sum_{i=1}^{3}w_i^{(t)}\bar f_{i,t}(\theta),
\label{eq:tchebycheff}
\end{equation}
where $\rho>0$ is a small augmentation coefficient. All feasible observations
are re-scalarized using the current weight vector at every iteration.

An ARD Mat\'ern-$5/2$ GP is fitted to the scalarized observations. For a
candidate protocol $\theta$, let $\mu_t(\theta)$ and $\sigma_t(\theta)$ denote
the GP posterior mean and standard deviation, respectively. For minimization,
the expected improvement is
\begin{equation}
 z_t(\theta)=\frac{g_t^{\mathrm{best}}-\mu_t(\theta)}{\sigma_t(\theta)},
\label{eq:ei_z}
\end{equation}
\begin{equation}
 \mathrm{EI}_t(\theta)=\bigl(g_t^{\mathrm{best}}-\mu_t(\theta)\bigr)\Phi\!\bigl(z_t(\theta)\bigr)+\sigma_t(\theta)\phi\!\bigl(z_t(\theta)\bigr),
\label{eq:ei}
\end{equation}
where $g_t^{\mathrm{best}}$ is the best scalar value among the evaluated
protocols, and $\Phi(\cdot)$ and $\phi(\cdot)$ are the cumulative distribution
and probability density functions of the standard normal distribution. The
next protocol is selected by
\begin{equation}
 \theta_{t+1}=\arg\max_{\theta}\mathrm{EI}_t(\theta).
\label{eq:next_protocol}
\end{equation}
The selected protocol is evaluated by the battery simulator and appended to
$D$, and the feasible Pareto archive $P$ is updated accordingly. This
scalarization--GP--EI loop remains active throughout the complete simulation
budget and forms the numerical backbone of LLMBO-MO.

\subsection{LLM-Informed Initialization}
\label{sec:warm_start}

The first LLM mechanism is introduced before sequential BO, when no
simulator-based surrogate is yet available. Inspired by the use of LLMs as a
natural-language interface to prior knowledge~\cite{refKuaiLLMBO}, the prompt
provides the battery context, the MCC structure, the bounds of the decision
variables, the optimization objectives, and qualitative knowledge about
multistage charging. The LLM returns a pool of numerical protocol candidates
together with a heuristic score used only for candidate ranking.

The raw LLM outputs are first checked against the protocol definition in
Section~\ref{sec:problem}. Non-numerical, non-finite, and duplicate candidates
are removed; bound violations are repaired; and candidates that cannot produce
a valid terminal SOC interval are rejected. These checks only enforce the
validity of the decision variables. Voltage and temperature feasibility are not
inferred by the LLM and are determined only after battery simulation.

To avoid selecting several similar LLM proposals, the initial portfolio is
constructed by balancing candidate quality, protocol preference, and diversity,
\begin{equation}
 J(\theta)=h(\theta)-\omega_p p(\theta)+\omega_m m(\theta)+\omega_d d(\theta),
\label{eq:portfolio}
\end{equation}
where $h(\theta)\in[0,1]$ is the LLM score, $p(\theta)$ penalizes an
undesirably small terminal SOC span, $m(\theta)$ rewards the preferred current
ordering, and $d(\theta)$ measures the distance from the protocols already
selected for the initial portfolio in normalized decision coordinates. The
coefficients $\omega_p$, $\omega_m$, and $\omega_d$ control the corresponding
terms. Randomly generated valid protocols are then added to preserve global
coverage and reduce the risk of relying on an inaccurate prior.

Every selected initial protocol is evaluated by the battery simulator before it
is added to $D$. Consequently, the LLM changes only the locations at which the
initial simulation budget is spent; it never supplies objective values to the
GP or the Pareto archive.

\subsection{Weight-Conditioned Regional Guidance}
\label{sec:region_pref}

After the initial dataset has been established, LLMBO-MO uses a second LLM
mechanism to refine acquisition optimization during the early sequential stage.
At iteration $t$, the prompt contains the current trade-off weight
$\mathbf w^{(t)}$, the observed objective ranges, the current best values,
representative evaluated protocols, and a compact summary of the optimization
state. Conditioning on $\mathbf w^{(t)}$ aligns the LLM suggestion with the
same trade-off direction currently optimized by the numerical MOBO backbone.

The LLM may return a candidate point, a bounded region, or no preference. A
returned point is expanded to a local region, while a returned region is parsed
and clipped to the valid decision-variable bounds. Invalid or excessively
narrow or broad regions are discarded. When a valid region is obtained, a small
number of anchor points are sampled from it and added to the starting points of
numerical EI maximization.

Importantly, the regional information does not modify the GP, the EI function,
the objective values, or the Pareto dominance relation, nor does it restrict
the search space to the LLM-recommended region. The original EI restarts and
the full decision space are always retained. Therefore, an uninformative or
invalid LLM response simply leaves the numerical acquisition search unchanged.
Regional guidance is used only for $t\le T_{\mathrm L}$; after this early
window, the optimization proceeds entirely with the numerical MOBO backbone.

\subsection{Overall Procedure}
\label{sec:overall_procedure}

Algorithm~\ref{alg:llmbo} summarizes LLMBO-MO. The method first constructs a
simulator-validated initial dataset using LLM-informed and random protocols.
It then repeatedly selects a trade-off direction, fits the scalar GP, maximizes
EI, evaluates the selected protocol, and updates the Pareto archive. During the
early iterations, weight-conditioned regional guidance provides additional EI
restarts. The final output is the feasible Pareto set formed entirely by
simulator-evaluated charging protocols.

\begin{algorithm}[!t]
\caption{LLMBO-MO}
\label{alg:llmbo}
\footnotesize
\begin{algorithmic}[1]
\Require Battery simulator, LLM, total budget $N$, initial budget $n_0$, weight set $W$, guidance horizon $T_{\mathrm L}$
\Ensure Feasible Pareto archive $P$
\State Generate and screen LLM candidate protocols
\State Select a diverse LLM portfolio and add random valid protocols
\State Evaluate the $n_0$ initial protocols; initialize $D$ and $P$
\For{$t=1$ to $N-n_0$}
    \State Select $\mathbf w^{(t)}\in W$ and compute $g_t$ using \eqref{eq:tchebycheff}
    \State Fit the GP and construct $\mathrm{EI}_t$ using \eqref{eq:ei}
    \If{$t\le T_{\mathrm L}$}
        \State Query the LLM with $\mathbf w^{(t)}$ and the current BO state
        \State Add valid regional anchors to the EI starting points
    \EndIf
    \State Select $\theta_{t+1}$ by maximizing EI
    \State Evaluate $\theta_{t+1}$ with the battery simulator and append the result to $D$
    \State Update the feasible Pareto archive $P$
\EndFor
\State \Return $P$
\end{algorithmic}
\end{algorithm}
